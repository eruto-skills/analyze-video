# QA Checklist

レポート出力前の最終確認項目。

## 必須チェック

- [ ] ナレーション全文を読み込んだ（部分読みでない）
- [ ] frontmatterに `title` / `channel` / `url` / `duration` / `upload_date` / `analyzed_date` / `tags` を設定した
- [ ] 構成マップ（時系列のブロック分割）を含む
- [ ] 6軸（または7軸）すべてに対し、ナレーションからの具体的な引用を含む
- [ ] 抽象評価（「良い」「効果的」）を具体的な手法記述に置き換えた
- [ ] ヘッジ表現の軸では具体表現を網羅的に列挙した
- [ ] 一時ファイル（VTT・TXT・メタJSON）を削除した

## 任意チェック

- [ ] 比較分析（`--compare` 指定時）の比較テーブルが軸ごとに揃っている
- [ ] Project Integration で File Placement が定義されている場合、その配置先に保存した
- [ ] Project Integration で Lint が定義されている場合、レポートに対して実行しエラーが残っていない

## アンチパターン

|やってはいけないこと|理由|
|-|-|
|長尺動画でナレーションを部分読みする|分析の精度が下がる|
|「構成が良い」等の抽象評価で軸を埋める|再現可能な知見にならない|
|ヘッジ表現の例を1〜2個で済ませる|高度な技法ほど網羅性が価値|
|軸7を Self-Reference 未設定でも書く|プロジェクト固有の文脈を持ち込んでしまう|
|中間ファイルを残す|レポートが成果物。中間物は混乱の元|
