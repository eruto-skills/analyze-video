# Analysis Axes

動画分析の7軸。各軸で「この動画がやっていること」と「なぜそれが効果的か」を、ナレーションからの具体引用付きで明記する。
抽象的な評価（「良い」「効果的」）は禁止。

## 軸1: フック・引き込み

冒頭で視聴者を引き込む手法。最初の30秒〜1分を精密に分析する。

着目点:

- 最初の一文は何か（問いかけ？宣言？データ？）
- 「なぜ今この話が重要か」をどう伝えているか
- 視聴者の不安・関心・好奇心のどれに訴えているか
- 冒頭で提示される「問い」の射程（動画全体をカバーしているか）

## 軸2: 情報密度とペーシング

単位時間あたりの情報量の配分。

着目点:

- 密度が高い区間と低い区間の交互パターン
- 「息継ぎ」の手法（具体例、繰り返し、要約）
- 早口で大量の情報を詰め込む区間があるか、その効果
- 重要度に応じた尺の配分（重要な話に長い時間をかけているか）

## 軸3: ヘッジ表現・炎上対策

断定を避ける表現、予防線、免責表現のパターン。

着目点:

- 「あくまで」「もちろん」「一概には言えない」等の頻出ヘッジ表現を列挙
- ヘッジの使い分け（どの主張にヘッジをかけ、どこは断定するか）
- 反論を先回りで潰す手法（「〜と思う方もいるかもしれませんが」）
- 情報源の明示（「〜によると」「報道によれば」）で責任を分散する手法
- 「個人の意見」と「事実」の境界をどう引いているか

> [!IMPORTANT]
> この軸は特に重要。センシティブなテーマを扱う動画ほどヘッジの技術が洗練されている。具体的な表現を網羅的に拾い出すこと。

## 軸4: 説得力・信頼性構築

視聴者に「この人の話は信頼できる」と思わせる手法。

着目点:

- 専門知識の提示方法（さりげなく？明示的に？）
- データ・出典の引用パターン
- 「私が調べた限り」等の個人的な調査努力の表現
- 複数の視点を提示してからの意見表明
- 限界の正直な提示（「ここは分からない」「情報が限られている」）

## 軸5: エンゲージメント維持

長尺動画で視聴者を飽きさせない工夫。

着目点:

- トピック転換の頻度とタイミング
- 問いかけ・修辞的質問の挿入頻度
- 具体例・エピソードの配置
- テンションの上げ下げ（文体の変化として字幕からも追える）
- 「次にお話しするのは」等の予告による期待感の醸成

## 軸6: 記憶に残るフレーズ

視聴後も頭に残る表現、引用したくなる一文。

着目点:

- 対比・対句構造（「AではなくB」「AであるがBでもある」）
- 数字を使った印象的な表現
- 比喩・アナロジー
- キーワードの反復（同じ言葉を何度も使って刷り込む手法）
- 結論を一文に凝縮したフレーズ

## 軸7（任意）: 自分のコンテンツへの応用

Project Integration で `Self-Reference` が設定されている場合のみ実施する。
上記6軸の分析を踏まえ、自分のコンテンツ制作に活かせるテクニックを抽出する。

着目点:

- 自分のジャンルでも使えるテクニックはどれか
- 動画の長さの違いを踏まえた適用方法
- すぐに取り入れられるもの vs 段階的に習得すべきもの
- 具体的な適用例（「次の動画の冒頭で〜する」レベルの具体性）

設定されていない場合、このセクションはレポートから省略する。
